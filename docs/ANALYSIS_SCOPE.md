# Analysis scope

1. Validation is hospital-disjoint internal–external cross-validation, not independent external validation.
2. The outcome is serum-creatinine-defined KDIGO stage 2–3 progression.
3. The prediction landmark is 12 hours; the outcome window is >12 through 72 hours.
4. SHAP values are non-causal model attributions.
5. Decision-curve analysis estimates net benefit and does not demonstrate improved patient outcomes.
6. Renal-marker ablation is post-hoc and exploratory.
7. No deployment threshold was selected by optimizing performance on held-out predictions.
