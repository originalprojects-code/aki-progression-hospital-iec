# Data access and Data Use Agreement

This repository does not contain eICU source data or patient-level derivatives.

The eICU Collaborative Research Database is accessed through PhysioNet by credentialed
users who complete the required human-subjects research training and accept the
applicable Data Use Agreement. Users must execute the SQL and notebooks in their own
authorized environment.

No repository license grants rights to redistribute eICU data. The MIT License applies
only to the original code and documentation in this repository.
