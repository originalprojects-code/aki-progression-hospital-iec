# Data access

The eICU Collaborative Research Database is hosted by PhysioNet. Access requires credentialing, human-subjects research training, and acceptance of the applicable Data Use Agreement. No patient-level data or restricted derivatives are distributed in this repository.

Required database citations:

- Pollard TJ et al. Scientific Data (2018). https://doi.org/10.1038/sdata.2018.178
- Pollard T et al. eICU Collaborative Research Database (version 2.0). PhysioNet (2019). https://doi.org/10.13026/C2WM1R
