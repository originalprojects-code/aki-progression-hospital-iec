# Aggregate outputs

Only manuscript-level, fold-level, threshold-level, feature-level, or cohort-flow
summaries are included. The repository excludes:

- patient-level rows;
- hospital-level hashed identifier tables;
- row-level predictions;
- row-level SHAP values;
- fitted model binaries;
- credentials and restricted source extracts.

Subdirectories follow the frozen workflow: feasibility, cohort/outcome, feature
inventory, feature matrix, modeling, analysis freeze, targeted strengthening, and
Table 1.
